SUPPLEMENTARY INFORMATION FOR "Learning Electronic Polarizations in Molecular Systems: Vibrational Spectroscopy of Ethanol-Water Mixtures"
==========================================================================================================================================

This folder contains the following subfolders; each has its own README.txt file:

* inputs  -- contains input files for the electronic structure theory calculations in the manuscript
* data    -- contains the data used to train ML models
* models  -- contains ML models and instructions for how to use them
* scripts -- contains any scripts needed for this work

Please contact d.wilkins@qub.ac.uk with any queries.
