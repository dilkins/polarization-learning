data
====

This folder contains a single extended-xyz file, frames.xyz, which has 8500 frames. The header line for each frame lists the elements to which Wannier centres have been assigned (i.e., elements_with_centres="C O"), the nuclear charges (i.e., list_of_charges="H 1 C 4 O 6"), the polarization from Wannier centres (e.g. wannier_polarization="20.74335846848703 12.524210494319163 -28.77806478087075"), a description of the calculation from which the frame was obtained (e.g., description=16_48_run_1 means a calculation with 16 water molecules and 48 ethanol molecules, of which this is from the first run), the frame number within that run (e.g. frame=35) and the preprocessed polarizability (e.g. mu="20.64875 12.39298 -28.69962")
